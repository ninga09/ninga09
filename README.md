## 👨‍💻 About Me

<img align="right" alt="DevOps & Cloud Architecture" width="370" src="https://cdn.dribbble.com/userupload/7725640/file/original-a2b82ab8779ece4c49df3672f7753ccb.gif">

Hello and welcome to my GitHub portfolio! I am a **Full Stack & DevOps Cloud Engineer** dedicated to building resilient distributed systems, modern full-stack web products, and automated cloud delivery pipelines.

My unique advantage is operating across the **entire product lifecycle**: from writing scalable backend APIs and frontend user interfaces to automating multi-environment infrastructure with **Terraform**, orchestrating clusters with **Kubernetes**, and securing delivery pipelines with **DevSecOps** best practices.

- 🔭 **What I'm currently working on:** Cloud-native microservices architectures, automated GitOps deployment workflows, and enterprise health-tech systems.
- 💡 **Core Philosophy:** *Zero manual repetitive tasks, high availability by design, and continuous automated validation.*
- 🎯 **Looking to collaborate on:** Open-source DevOps tooling, enterprise cloud migrations, and full-stack SaaS applications.

- **Infrastructure as Code (IaC):** Writing maintainable, modular Terraform configurations and Ansible playbooks to ensure reproducible environments.
- **Container Orchestration:** Crafting optimized multi-stage Docker containers and managing production-ready Kubernetes workloads using Helm charts and ArgoCD.
- **Continuous Delivery (CI/CD):** Designing pipelines that automate linting, unit tests, security scans (SonarQube/Trivy), Docker image publishing, and deployment.
- **Observability & Reliability:** Implementing real-time system monitoring, distributed log aggregation, and metric alerting with Prometheus, Grafana, and the ELK stack.
- **Zero-Downtime Releases:** Rolling updates, Blue/Green, and Canary deployments ensuring continuous system availability.
